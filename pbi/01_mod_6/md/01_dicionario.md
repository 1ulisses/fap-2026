# Dicionário de Dados
## 1. Sobre

  Dicionário de Dados da tabela de acidentes rodoviários pela PRF em 2025.

## 2. Dicionário

| Variável | Tipo Atual | Descrição |
|---|---|---|
| `id` | int64 | Identificador único do registro. |
| `data_inversa` | str | Data do acidente. |
| `dia_semana` | str | Dia da semana do acidente. |
| `horario` | str | Hora do acidente. |
| `uf` | str | Sigla do estado. |
| `br` | int64 | Número da rodovia federal. |
| `km` | str | Quilômetro da rodovia. |
| `municipio` | str | Município do acidente. |
| `causa_acidente` | str | Causa principal do acidente. |
| `tipo_acidente` | str | Tipo de acidente. |
| `classificacao_acidente` | str | Classificação quanto às vítimas. |
| `fase_dia` | str | Fase do dia. |
| `sentido_via` | str | Sentido da via. |
| `condicao_metereologica` | str | Condição meteorológica. |
| `tipo_pista` | str | Tipo de pista. |
| `tracado_via` | str | Traçado da via. |
| `uso_solo` | str | Uso do solo. |
| `pessoas` | int64 | Total de pessoas envolvidas. |
| `mortos` | int64 | Total de mortos. |
| `feridos_leves` | int64 | Total de feridos leves. |
| `feridos_graves` | int64 | Total de feridos graves. |
| `ilesos` | int64 | Total de ilesos. |
| `ignorados` | int64 | Total de casos ignorados. |
| `feridos` | int64 | Total de feridos. |
| `veiculos` | int64 | Total de veículos envolvidos. |
| `latitude` | str | Latitude do local. |
| `longitude` | str | Longitude do local. |
| `regional` | str | Regional da PRF. |
| `delegacia` | str | Delegacia da PRF. |
| `uop` | str | Unidade Operacional. |
| `acidente_fatal` | int64 | Indicador de acidente fatal. |
| `mes` | int64 | Mês do acidente. |
